💻 Drizzle ORM TypeScript Kodidan Namuna (`assets` Bosh Jadvali):

export const assets = pgTable('assets', { id: uuid('id').defaultRandom().primaryKey(), organizationId: uuid('organization_id').references(() => organizations.id).notNull(), roomId: uuid('room_id').references(() => rooms.id).notNull(), customLabel: varchar('custom_label', { length: 100 }).notNull(), // Inson kodi: E-210-xona-001 secretToken: varchar('secret_token', { length: 32 }).notNull().unique(), // Mashina siri: tk_TATU_9xK2A7zP initialCost: decimal('initial_cost', { precision: 15, scale: 2 }), status: assetStatusEnum('status').default('active').notNull(), createdAt: timestamp('created_at').defaultNow().notNull(), }, (table) => ({ orgRoomIdx: index('idx_assets_org_room').on(table.organizationId, table.roomId), tokenIdx: uniqueIndex('idx_assets_secret_token').on(table.secretToken), }));

⚡ Trillionlik Masshtabda 0.005 Sekundlik Qidiruv Qanday Ta'minlanadi?

1. `assets.secret_token` Ustunida B-Tree UNIQUE Indeks: Telefon kamerasi QR-kodni tutishi bilan, backend milliardlab aktivlar ichidan aynan shu jihozni 0.001 soniyada topib beradi.
2. `assets(organization_id, room_id)` Kompozit Indeksi: Auditor 210-xonaga kirganda, butun universitet bo'yicha emas, faqat shu xonadagi 25 ta partani 0.004 soniyada ekranga chiqaradi.
3. PostgreSQL Table Partitioning (OTMlar bo'yicha Sharding): 250 ta universitetning har biri o'zining bo'limiga ega bo'lgani uchun, TATU so'rovi O'zMU yoki SamDU bazasiga umuman tegmaydi.

🛡️ 5 ta Rolning Baza Darajasidagi Ruxsatlar Matritsasi (RBAC)

• Superadmin: Faqat `organizations` va `subscriptions` bilan ishlaydi. Universitet ichidagi xonalar va partalarga kira olmaydi.
• Universitet Admini: `departments`, `buildings`, `rooms`, `profiles` ni boshqaradi va audit jarayonini to'liq nazorat qiladi.
• Boshliq (Rektor / Prorektor): 100% Read-Only! Barcha 24 ta jadval bo'yicha chuqur tahlil (drill-down) ko'radi, lekin bitta ham o'zgartirish kirita olmaydi.
• Ro'yxatga Oluvchi (Registrar): `assets` kiritadi, `custom_label` beradi, `qr_print_batches` chiqaradi va `asset_transfers` qiladi. Xona ocha olmaydi.
• Tekshiruvchi (Auditor): Faqat `audit_items` ga skanerlash natijalarini yozadi. Narx, nom yoki xonalarni o'zgartira olmaydi.
