AssetAudit (MulkNazorat) — 24 ta Jadvaldan Iborat Baza Arxitekturasi

250 ta Universitet, 10–50 milliard aktivlar, HEMIS va UzASBO/1C integratsiyasi, buxgalteriya harakatlari, maxfiy Base62 tokenlar va dala auditi uchun mukammal modulli relyatsion arxitektura.

1-Modul: Multi-Tenant & Shartnomalar Boshqaruvi
3 ta Jadval
organizations PK: id
250 ta universitet reestri, STIR (INN), qisqa prefiks va faollik holati.
idUUID
slug / codeVARCHAR(10) (TATU, OZMU)
nameVARCHAR(255)
statusENUM ('active', 'frozen')
contract_end_atTIMESTAMP
subscriptions PK: id
Shartnoma muddatlari, obuna paketi, aktivlar limiti va to'lov hisoblari.
idUUID
organization_idUUID FK -> org
plan_tierVARCHAR(50)
max_assets_limitBIGINT (50,000,000,000)
is_paidBOOLEAN
integration_settings PK: id
HEMIS, UzASBO va 1C tizimlari bilan avtomatlashgan bog'lanish API kalitlari.
idUUID
organization_idUUID FK -> org
providerENUM ('hemis', 'uzasbo', '1c')
api_endpointTEXT
auth_token_encryptedTEXT
